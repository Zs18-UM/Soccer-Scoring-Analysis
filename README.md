# Soccer-Scoring-Analysis
Compares scoring data between international friendlies and tournament matches.

**Findings**

Data shows that in roughly 49,000 international soccer matches from 1872 - 2024, friendly matches have an average of 2.875 goals per game vs. 2.689 goals per game in tournament matches. This also aligns with the average goal margin of 1.536 for friendlies vs. 1.443 for tournament matches. This shows that tournament matches produce fewer high-scoring or lopsided matches.

**Process**

I began this project by separating friendlies from tournament matches. I then limited the tournament matches to only the major tournaments (such as the Euros, Copa America, and World Cup). Next, I created a pivot table that displayed the average number of goals scored per game and the average goal margin per game for both friendlies and tournament matches. I then used the pivot tables to create my charts, which are shown on the dashboard, which was finished with slicers that allow users to view the stats for each tournament rather than all of them together.

**Interpretation**

One explanation for this may be tactical setup. Coaches may be more cautious in tournament matches because there is more at stake, and they are less willing to take risks when deciding line-ups or tactics. Another theory is the difference in opponent quality. To play in these tournaments, nations must first go through a qualification period, in which only the top nations qualify. The qualification period raises the standards for these games and closes the skill gap. On the other hand, friendlies can be played by any nation, so top teams can play teams at the bottom of the rankings and potentially run up the score, skewing the data in this study.

**Next Steps**

A next step to take to test this second theory would be to compare the goals scored and goal margin in games between two nations with similar rankings and two nations on opposite sides of the rankings.
